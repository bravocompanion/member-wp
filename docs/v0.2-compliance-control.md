# Member WP v0.2 — Compliance Control Center

## Tujuan

v0.2 mengubah Member WP dari master-data viewer menjadi control center operasional. Admin dapat menentukan kewajiban per WP, mengontrol task bulanan/tahunan, menyimpan catatan timeline, dan melihat pekerjaan yang membutuhkan perhatian.

## Prinsip penting: kewajiban harus dikonfirmasi admin

`obligation_catalog` hanya menyediakan katalog pilihan UI. Sistem **tidak** mengaktifkan PPh/PPN/SPT berdasarkan `taxpayer_type`. Hubungan yang benar disimpan di `compliance_obligations` setelah admin mengonfirmasi profil WP.

Ketika profil disimpan, route `/api/compliance/profile` membuat task untuk periode berjalan. Task baru tidak memiliki `due_date` sampai admin mengisinya. Ini menghindari hard-code tanggal legal/regulasi ke aplikasi.

## Tabel baru

- `obligation_catalog`: katalog pilihan kewajiban untuk UI.
- `compliance_obligations`: profil kewajiban yang sudah dikonfirmasi per WP.
- `compliance_period_tasks`: status kerja per masa/tahun.
- `taxpayer_notes`: timeline catatan, kategori, dan pin.
- `attention_items`: attention manual/system tambahan.

Attention Center juga menurunkan attention secara dinamis dari task compliance dan `taxpayer_issues`, sehingga task `blocked`, `waiting_documents`, `waiting_client`, `waiting_review`, dan task lewat deadline dapat muncul tanpa harus membuat record attention manual.

## Status task

- `not_started`
- `waiting_documents`
- `in_progress`
- `waiting_review`
- `waiting_client`
- `blocked`
- `completed`
- `not_applicable`

## Audit

Perubahan melalui API v0.2 menulis event ke `activity_logs`:

- `compliance_profile_updated`
- `compliance_task_updated`
- `taxpayer_note_created`

## Demo mode

Next.js demo mode (`DEMO_MODE=true`) menggunakan 233 WP sintetis dan tidak terhubung ke Supabase. Perubahan write tidak dipersistenkan pada mode ini. Credential asli tidak pernah dimasukkan ke repository publik.
